Ultimate Recreational Mapping App
# 🗺️ SportsmanMap Pro

The ultimate recreational mapping app for hunters, anglers, and outdoor enthusiasts.

## ✨ Features

### 🗺️ 10 Base Maps
- OpenStreetMap
- Satellite Imagery (Esri)
- USGS Topographic
- National Geographic
- Dark Mode (CartoDB)
- Light Clean (CartoDB)
- Outdoors / OpenTopoMap
- Stamen Terrain
- Hybrid Labels
- USGS Imagery Only

### 🦌 Hunting Layers
- Wildlife Management Unit boundaries
- Deer stand locations
- Turkey zones (spring & fall)
- Waterfowl areas
- Pheasant habitat (CRP/WRP)

### 🎣 Fishing Layers
- Lakes & rivers with species info
- Boat launches & public access
- Designated trout streams
- Ice fishing hot spots

### 🥾 Recreation Layers
- Hiking trails
- ATV/OHV routes
- Campgrounds
- Snowmobile trail network

### 🌲 Land Layers
- Public land boundaries
- Private land (no-trespass)
- County property parcels
- Topographic contours
- Hillshade terrain

### 🌦️ Environmental Layers
- Live NOAA weather radar
- Wind direction/speed
- NWI Wetlands
- NASA active fire data

### ⚙️ Settings Panel
- Moveable: Top / Left / Right / Bottom
- Collapsible with arrow toggle
- Gear icon reopens panel
- 5 color themes (Blue/Green/Red/Purple/Orange)
- Light & Dark mode toggle
- Mini-map toggle
- Scale bar toggle
- Coordinate display with format options

### 📌 Pin System
- Drop pins anywhere on map
- 12 emoji pin types
- Name, notes, and category
- Saved in browser cookies (365 days)
- Export as GPX, KML, or JSON

### 🌤️ Weather Tab
- Real-time conditions via Open-Meteo
- 5-day forecast
- Sunrise/sunset times
- Moon phase & illumination
- Solunar fishing activity times

### 📏 Tools
- Distance measuring tool
- GPS/location tracking
- Address search (Nominatim)
- Share map link
- Fullscreen mode
- Coordinate copy

## 🔌 Free APIs Used
- [Open-Meteo](https://open-meteo.com) - Weather (no key)
- [Nominatim/OSM](https://nominatim.org) - Search & reverse geocoding (no key)
- [OpenStreetMap](https://openstreetmap.org) - Base map tiles (no key)
- [USGS National Map](https://basemap.nationalmap.gov) - Topo tiles (no key)
- [Esri ArcGIS Online](https://arcgis.com) - Satellite & terrain tiles (no key)
- [CartoDB](https://carto.com) - Dark/light base maps (no key)
- [Iowa Mesonet NEXRAD](https://mesonet.agron.iastate.edu) - Radar tiles (no key)
- [FWS Wetlands](https://fws.gov/wetlands) - Wetland tiles (no key)
- [OpenTopoMap](https://opentopomap.org) - Topo tiles (no key)
- [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov) - Fire data (no key)
